Session Brief and Continuity

How a writing session starts: the app picks the entries by rule, Claude writes one page from only those entries, and every claim cites an entry the code can check. Then the alignment check reads the chapter back against the bible and the stored plot.

Example bible: East Winds canon planned idea Every control below changes the simulated state on this page. The app is general purpose; East Winds is the first bible loaded into it.
