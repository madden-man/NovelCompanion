6. **Tests**: `settings.spec.ts` rows prefixed with their criterion (a number saves and the grid span follows; the unit; a template is used; an era default is copied into a new bible; an instruction saves, resets, and the footer stays; prune shows the count and asks for the word), `editing.spec.ts` Lists rows (move, re-parent, colour, kind, regions rename renames on an event, age group from and to), `app.spec.ts` (All sections lists every collection and a row renames), `tree.spec.ts` (legend rename and colour), NF-2 by keyboard in both themes.
